What is cross-site scripting?  Describe some of its dangers and options to mitigate them.
Injecting malicious code into a request to change the behavior of a POST, GET, etc response. 

Dangers: if your page saves form data and displays it can affect the page permanently for other users. 
If a url is provided with the malicious code it could redirect a user.

Mitigate:  scrub, filter data being entered in.

What is a SQL injection attack?  Describe some of its dangers and options to mitigate them.

Injecting malicious SQL code into a request.
Dangers of this could affect any data in the SQL Database. 
Mitigate: scrub, filter data being entered. removing special characters
